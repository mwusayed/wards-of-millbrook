# Game Design Document (modular)

One file per system, each with the same eight sections: Overview · Player fantasy · Detailed rules · Formulas ·
Edge cases · Dependencies · Tuning knobs · Acceptance criteria. Formulas name the constant they come from;
acceptance criteria name the test or evidence that proves them. See `docs/WORKFLOW.md` §4.
